ENERGY TRADING QUANT PROJECT Day-Ahead vs Real-Time Power Spread
Forecasting and Virtual Trading Backtest

OVERALL PROJECT SCOPE

The goal of this project is to design, implement, and rigorously
evaluate a systematic trading strategy that forecasts Day-Ahead (DA) vs
Real-Time (RT) electricity price spreads and simulates virtual trading
profitability under realistic market constraints.

This project should demonstrate: - Deep understanding of power market
structure - Strong data engineering capability - Time-series modeling
discipline (no look-ahead bias) - Risk-aware backtesting - Clean,
production-quality Python code - Clear communication of assumptions,
limitations, and results

The final repository should resemble a research-grade trading framework
rather than a notebook experiment.

[x] Simulate realistic P&L calculations -> gross_pnl = signal × position_mwh ×
    actual_spread; net_pnl = gross_pnl - transaction_cost_paid
[x] Track cumulative returns -> cumulative_pnl = net_pnl.cumsum() column in
    trade_df; per-hour granularity for equity curve plotting
[x] Compute performance metrics:
    - Annualized return -> total_pnl × 8760 / n_obs
    - Sharpe ratio -> mean(pnl) × sqrt(8760) / std(pnl, ddof=1)
    - Sortino ratio -> mean(pnl) × sqrt(8760) / sqrt(mean(min(pnl,0)^2))
    - Max drawdown -> max(cumsum.cummax() - cumsum)
    - Win rate -> fraction of trading hours with net_pnl > 0
    - Tail risk (CVaR) -> mean(pnl[pnl <= quantile(pnl, 0.05)])
[x] Stress test during high volatility periods (esp. Uri Feb 2021)
    -> Uri regime isolated in compute_regime_metrics(); Sharpe=14.92 (264 hrs)

    -> compute_regime_metrics() in risk.py; 11 regimes documented in Phase 6
